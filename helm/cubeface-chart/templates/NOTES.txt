CubeFace has been deployed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Wait for the pod to become ready:

   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ $fullname }}

{{- if eq $mode "postgres" }}

   The managed PostgreSQL cluster takes a little longer to bootstrap:

   kubectl -n {{ .Release.Namespace }} get cluster {{ include "cubeface.postgresClusterName" . }}
   kubectl -n {{ .Release.Namespace }} get pods -l cnpg.io/cluster={{ include "cubeface.postgresClusterName" . }}
{{- end }}

{{- if .Values.ingress.enabled }}

2. Open {{ $origin }}{{ $base }}

   The Ingress serves everything under the path prefix {{ include "cubeface.ingressPath" . }}.
   Make sure DNS for {{ first .Values.ingress.hosts }} points at your ingress controller.
{{- else }}

2. No Ingress is enabled. Use a port-forward (the local port must match
   config.PORT so the browser origin matches PUBLIC_ORIGIN):

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }} {{ .Values.config.PORT }}:{{ .Values.service.port }}
   # then open {{ $origin }}{{ $base }}
{{- end }}

3. Configuration notes:

{{- if eq $mode "postgres" }}
   - Database: CloudNativePG cluster {{ include "cubeface.postgresClusterName" . }}
     ({{ .Values.database.postgres.instances }} instance(s), writable service
     {{ include "cubeface.postgresAddr" . }}).
     {{- if .Values.database.postgres.operator.install }}
     The vendored CloudNativePG operator was installed with this release.
     {{- else }}
     CloudNativePG was assumed to be installed already.
     {{- end }}
     Connection credentials are in Secret {{ include "cubeface.postgresAppAuthSecretName" . }};
     the app DSN is in Secret {{ include "cubeface.postgresDSNSecretName" . }}.
     {{- if .Values.database.postgres.retain }}
     The Cluster carries helm.sh/resource-policy: keep: `helm uninstall` leaves
     the database and its PVCs in place. Delete the Cluster manually only when
     you mean to destroy all data.
     {{- else }}
     The Cluster is deleted together with the release, including all data.
     {{- end }}
{{- else if eq $mode "external" }}
   - Database: external PostgreSQL. CubeFace runs AutoMigrate on startup, so the
     DSN user needs CREATE/ALTER privileges on its schema.
{{- else }}
   - Database: SQLite at /data/cubeface.db on PVC {{ .Values.persistence.existingClaim | default (include "cubeface.pvcName" .) }}.
     SQLite is single-writer, so replicaCount must stay at 1.
     {{- if .Values.persistence.retain }}
     The PVC carries helm.sh/resource-policy: keep: `helm uninstall` leaves it
     (and all user data) in place. Delete it manually only when you mean to.
     {{- else }}
     The PVC is deleted together with the release, including all user data.
     {{- end }}
{{- end }}
{{- if .Values.secret.create }}
   - The chart generated SESSION_SECRET and stored it in Secret
     {{ include "cubeface.secretName" . }}. Back it up: losing it invalidates
     all existing sessions. Set secrets.SESSION_SECRET to manage it yourself.
{{- else }}
   - Credentials are read from the pre-existing Secret
     {{ include "cubeface.secretName" . }}; it must contain SESSION_SECRET{{ if eq $mode "external" }} and SQL_DSN{{ end }}.
{{- end }}

4. Useful values:

   --set config.BASE_PATH=/cubeface         serve under a path prefix
   --set config.PUBLIC_ORIGIN=https://...   override the auto-detected origin
   --set database.mode=sqlite               use a PVC-backed SQLite file instead
   --set database.mode=external \
     --set database.external.dsn=...        use an existing PostgreSQL server
   --set database.postgres.instances=3      PostgreSQL HA size (postgres mode)
   --set database.postgres.storage=20Gi     PostgreSQL volume size
   --set database.postgres.operator.install=false
                                            reuse an existing CloudNativePG operator
